# Shastra — Awakening Education

> *"Education is the manifestation of the perfection already in man."* — Swami Vivekananda

Shastra is a Vivekananda-inspired education platform that measures **character over marks** — tracking four behavioural pillars instead of test scores.

---

## What It Does

| Metric | Sanskrit | Measures |
|--------|----------|----------|
| 🔥 Concentration | एकाग्रता | Sustained focus during a session |
| 🌳 Self-Reliance | आत्मनिर्भरता | Working independently without hints |
| ⚡ Perseverance | दृढ़ता | Healthy resilience through retries |
| ⭐ Confidence | आत्मविश्वास | Calibration between self-rating & actual |
| 🛡️ **Character** | **चरित्र** | Composite of all four (25% each) |

## Quick Start

```bash
git clone https://github.com/Nitinmittal373/HACKATHON_DTU_2026.git
cd HACKATHON_DTU_2026

# Frontend — open directly (zero build step)
open frontend/index.html

# Backend
cd backend
cp .env.example .env
npm install
npm run dev     # http://localhost:5000
```

## Design Language

- **Saffron** `#e07020` — primary action, energy, focus
- **Maroon** `#6b1a2a` — topbar, headings, authority
- **Gold** `#c8941a` — accent, progress bars
- **Cream** `#f5e8cc` — backgrounds, cards

Om (ॐ) appears throughout as a motif of inner excellence — not decoration, but a reminder that every score is a measure of the student's inner growth, not their comparison to others.
